# Tõlk — EN · ET Field Translator

This folder contains everything needed to host the app on GitHub Pages.

## Upload steps
1. Create a new **public** repository on GitHub.
2. On the repo page, click "uploading an existing file."
3. Drag in `index.html` from this folder (already correctly named — no renaming needed).
4. Commit the change.
5. Go to Settings → Pages → set Source to "Deploy from a branch," branch `main`, folder `/ (root)`, then Save.
6. Your live link will appear at the top of that Pages settings screen after about a minute.
7. Open the link on your iPhone in Safari → Share → Add to Home Screen.
